# **App Name**: VaultSpace

## Core Features:

- Asset Upload: Users can upload documents, images, links, and environment keys.
- Role-Based Access: Admins have full control; users can upload, view shared data, and edit only their own uploads.
- Activity Logging: Logs every action, especially views and copies of sensitive keys, for accountability.
- Admin Dashboard: Admins monitor user activities, manage roles, and send notifications.
- Key Rotation Notification: Admins can use a tool to send notifications for critical tasks like API key rotation to the relevant users

## Style Guidelines:

- Primary color: Deep blue (#293462) for trust and security.
- Background color: Light gray (#E5E9F2) to provide a clean, uncluttered backdrop.
- Accent color: Teal (#2E8A99) for interactive elements and highlights.
- Body and headline font: 'Inter' for a modern, neutral, and readable interface.
- Use simple, professional icons representing different types of assets (documents, links, keys).
- Clean, organized layout with clear sections for asset types, user roles, and activity logs.
- Subtle transitions and animations for a smooth user experience.
